2. 주요 작업 내용

✅ 패키지 빌드 및 환경 구축
catkin_ws 워크스페이스 내 모든 패키지 빌드 성공 (ssafy_msgs, ssafy_bridge, sub1, sub2 등).

ROS2 및 로컬 패키지 환경 변수 설정 스크립트 실행 확인.

DOS
call C:\dev\ros2_eloquent\setup.bat
call C:\Users\SSAFY\Desktop\catkin_ws\install\local_setup.bat
✅ ssafy_bridge 실행
시뮬레이터와 ROS2 간의 데이터 중계를 위한 브릿지 노드 가동.

DOS
cd C:\Users\SSAFY\Desktop\catkin_ws\src\ros2_smart_home\ssafy_bridge\launch
ros2 launch ssafybridge_launch.py
실행 확인: udp_to_pub, sub_to_udp, udp_to_cam, udp_to_laser 프로세스 정상 시작.

✅ 데이터 수신 확인 (rqt)
rqt 토픽 모니터를 통해 시뮬레이터로부터의 실시간 데이터 유입 확인.

확인된 주요 토픽:

/turtlebot_status: 차량 상태 정보 (위치, 속도 등)

/envir_status: 환경 데이터 (상태 정보)

/app_status: 스마트홈 가전 상태

3. 발생 이슈 및 해결 (Troubleshooting)

❌ ModuleNotFoundError: No module named 'attr'
원인: squaternion 라이브러리 실행에 필요한 attrs 패키지 누락.

해결: pip install attrs 명령어를 통한 라이브러리 추가 설치.

❌ OSError: [WinError 10048] (포트 충돌)
원인: 이전 실행 프로세스가 완전히 종료되지 않아 네트워크 포트(UDP)를 점유 중임.

해결: 작업 관리자에서 관련 .EXE 프로세스 종료 및 시뮬레이터 재시작 후 정상 동작.
