프로젝트에 본격적으로 착수하기 전에, 관련 기술 스택과 선행 학습 내용을 먼저 정리해두었습니다. 자율주행 시뮬레이션 기반 프로젝트인 만큼 어떤 시뮬레이션 환경을 사용할 수 있는지부터 조사했고, 대표적으로 CARLA, LGSVL(SVL Simulator), Gazebo/ROS 기반 시뮬레이션, AirSim, Webots 같은 도구들의 특징과 적용 가능성을 비교해보았습니다. 또한 센서 구성(카메라·LiDAR·IMU 등) 지원 범위, 맵/시나리오 제작 난이도, ROS 연동 가능 여부, 성능 요구사항 등을 기준으로 우리 프로젝트에 적합한 방향을 미리 고민했습니다.

동시에 제가 관심 있는 시스템 프로그래밍 요소를 자율주행 시뮬레이션에 어떻게 자연스럽게 녹여낼 수 있을지도 사전에 구상해보았습니다. 예를 들어 시뮬레이터와 실제 제어 모듈 사이의 데이터 파이프라인을 고성능으로 구성하거나, 센서 데이터 처리/전송 지연을 줄이기 위한 IPC(프로세스 간 통신) 설계, 멀티스레딩 기반의 실시간 처리 구조, 로깅·모니터링·프로파일링 체계 구축처럼 “시뮬레이션이 돌아가는 시스템 자체를 더 안정적이고 빠르게 만드는 역할”로 기여할 수 있겠다고 판단했습니다. 이런 준비를 통해 프로젝트 초기에 기술 선택과 구현 방향을 더 빠르게 결정할 수 있도록 기반을 마련해두었습니다.
