# 프로젝트 진행 기록

## 2026.03.03

### 프로젝트 주제 선정

프로젝트의 기본 방향을 정하기 위해 다음과 같은 조건을 먼저 정의하였다.

프로젝트 요구 조건
- 카메라 기반 AI 판단 기능
- 자율주행 로봇 활용
- IoT 요소 포함
- (선택) 게이미피케이션 요소 고려

위 조건을 만족하는 아이디어를 브레인스토밍한 결과  
실내 환경에서 작물 상태를 관리할 수 있는 자율주행 로봇 시스템을 프로젝트 주제로 선정하였다.

선정된 프로젝트 컨셉은 **실내 원예 관리 자율주행 로봇**이다.

이 시스템은 자율주행 로봇이 실내 환경을 이동하면서 카메라 기반 AI를 통해 작물 상태를 분석하고  
IoT 센서를 통해 환경 데이터를 수집하여 작물 관리 효율을 높이는 것을 목표로 한다.

## 2026.03.04

### 프로젝트 주제 구체화

초기 컨셉이었던 실내 원예 관리 로봇을 실제 활용 가능한 환경 중심으로 구체화하였다.

적용 환경은 **비닐하우스 기반 스마트 농업 환경**으로 설정하였다.

비닐하우스 환경을 선택한 이유는 다음과 같다.

- 비교적 일정한 구조로 로봇 자율주행 경로 설계가 용이함
- 작물 관리 작업이 반복적으로 이루어짐
- 환경 데이터 수집 및 자동화 시스템 적용 가치가 높음

또한 관리 대상 작물을 **토마토**로 선정하였다.

선정 이유
- 스마트팜에서 활용도가 높은 대표 작물
- 카메라 기반 AI를 통해 생육 상태 및 병해 여부 분석 가능
- 환경 데이터 기반 생육 관리 연구 사례가 많음

## 2026.03.05

### 시뮬레이션 환경 학습

로봇 개발을 위한 시뮬레이션 환경을 이해하기 위해  
SSAFY 시뮬레이터와 Gazebo를 비교하며 학습을 진행하였다.

비교 대상
- SSAFY Simulator
- Gazebo

학습 내용
- 로봇 시뮬레이션 환경 구조 이해
- 로봇 모델 및 센서 적용 방식 확인
- 실제 로봇과 시뮬레이터 환경의 차이점 파악

Gazebo 학습 과정에서는 다음과 같은 내용들을 중심으로 이해하였다.

- 로봇 모델 파일 구조(SDF / URDF)
- 센서 시뮬레이션 구성 방식
- ROS와 연동되는 로봇 시뮬레이션 환경 구조

## 2026.03.06

### 개발 환경 구축

팀 프로젝트 진행을 위해 개발 환경을 통일하는 작업을 진행하였다.

먼저 로봇 개발 및 시뮬레이션 환경 구성을 위해  
**Ubuntu 기반 Linux 환경을 구축**하였다.

또한 기존 Windows 환경과 병행 사용을 위해  
**Dual Boot 환경을 구성**하였다.

Dual Boot 구성 목적
- ROS 및 Gazebo 기반 개발 환경 확보
- 로봇 시뮬레이션 실행 환경 확보
- 팀원 간 동일한 개발 환경 유지

이와 함께 팀 협업을 위한 **Git 협업 규칙(Git Convention)**을 정의하였다.

설정한 협업 규칙
- 브랜치 전략 정의
- 커밋 메시지 작성 규칙 설정
- 협업을 위한 Git 워크플로우 정리

이를 통해 프로젝트 진행 과정에서 일관된 코드 관리와 협업 환경을 구축하였다.
