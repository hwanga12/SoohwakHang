## 2026-03-25 백엔드 실행 정정

- `REPO_ROOT`를 사용하는 백엔드 명령도 반드시 `S14P21A602` 저장소 내부에서 시작해야 합니다.
- Ubuntu 24.04 계열에서는 시스템 Python 전역 `pip install`이 PEP 668 때문에 막힐 수 있으므로, 백엔드는 `backend/.venv` 가상환경을 팀 공통 기준으로 사용합니다.

```bash
cd /path/to/S14P21A602   # 예: cd ~/SSAFY/S14P21A602
export REPO_ROOT="$(git rev-parse --show-toplevel)"

cd "$REPO_ROOT/backend"
python3 -m venv .venv
source .venv/bin/activate
`
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

- 이미 `.venv`가 준비된 팀원은 `python3 -m venv .venv`와 `python -m pip install -r requirements.txt`를 반복할 필요 없이 활성화 후 실행만 하면 됩니다.
