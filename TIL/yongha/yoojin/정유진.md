# 2026.03.09. 개발기록

## 3. 오늘 진행한 내용

### 3-1. 프로젝트 방향 정리

- 작물은 토마토 기준으로 우선 진행하기로 결정
- 단순 분류 프로젝트가 아니라, 최종적으로는 **고도화된 탐지 모델**까지 확장하는 방향으로 정리
- Gazebo는 주행/시연 환경으로 사용하고, AI는 실사 기반 작물 상태 인식 모델로 개발하는 방향 확정

### 3-2. 데이터셋 조사

AI Hub 후보 데이터셋을 비교한 결과, 아래 데이터셋을 메인 후보로 선정했다.

- **식물 병 유발 통합 데이터 (datasetkey: 525)**

토마토 데이터에는 정상, 병해, 생리장해, 작물보호제 처리반응 등이 포함되어 있으며,  
향후 분류뿐 아니라 탐지/고도화에도 활용 가능하다고 판단했다.

### 3-3. 데이터 다운로드 방식 결정

- 브라우저 직접 다운로드 대신 **aihubshell** 사용
- WSL/Linux 환경에서 직접 다운로드 및 관리하는 방식 채택
- 원본 데이터는 repo 내부가 아니라 **외부 데이터 경로(`~/datasets/...`)**에서 관리하기로 결정

### 3-4. 프로젝트 구조 방향 정리

원본 데이터는 repo 밖에서 관리하고, 프로젝트 repo 안에는 코드/설정/문서만 두는 방향으로 정리했다.

예시:

- 데이터: `~/datasets/aihub_525_tomato/...`
- 프로젝트: `~/aiot/tomato_ai/...`

### 3-5. AI 실험 환경 세팅

- `python3 -m venv .venv`
- 주요 패키지 설치 완료
  - opencv-python
  - scikit-learn
  - tqdm
  - matplotlib
  - torch
  - torchvision

### 3-6. 스크립트 파일 생성

다음 스크립트 파일 초안을 생성했다.

- `build_tomato_cls_dataset.py`
- `preview_tomato_annotations.py`
- `train_tomato_classifier.py`

현재는 토마토 데이터셋을 기반으로

1. JSON 파싱
2. 클래스 추출

   까지 이어지는 파이프라인을 준비 중이다.
