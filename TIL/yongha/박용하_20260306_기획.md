# 스마트팜 작물 상태 진단 AI MVP

## 1. 프로젝트 개요
터틀봇 기반 스마트팜/가드닝 로봇에 탑재할 **작물 상태 진단 AI 모델**을 개발한다.  
현재 MVP 목표는 **토마토 이미지에 대해 `NORMAL(정상)` / `ABNORMAL(이상)`을 분류**하는 것이다.

- **적용 환경**: Gazebo + ROS2 (추후 연동)
- **현재 완료 범위**: 데이터 다운로드 → 전처리 → 학습용 데이터셋 생성 → Colab 학습 → ONNX export → 단일 샘플 추론 검증

---

- **데이터셋명**: AI Hub 525 - 식물 병 유발 통합 데이터
